# Run and deploy your AI Studio app

> **Note:** MapChat has been merged into the Where2Go monorepo at `apps/web`. The production app uses the same UI with the Where2Go recommendation engine. This standalone Vite+Express folder is kept for reference only.

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/a16aad99-d820-4a63-8607-d1b2c72daa2b

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
